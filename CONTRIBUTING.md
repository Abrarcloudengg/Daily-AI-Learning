# Contributing

Thank you for your interest in contributing to Daily AI Learning.

## Ways to contribute

- Report issues or feature requests in the repository issue tracker.
- Improve curriculum structure and topic metadata under `config/`.
- Fix bugs or improve generated lesson quality in `src/daily_ai_learning/`.
- Enhance documentation, README, or automation.

## Development workflow

1. Fork the repository.
2. Create a feature branch.
3. Open a pull request against `main`.
4. Ensure tests and CI pass.

## Commit guidelines

- Use clear, descriptive commit messages.
- Keep each PR focused on a single problem.
- Rebase or merge the latest `main` before finalizing your PR.

## Code style

This project uses simple Python conventions with a focus on readability.
Please keep new code easy to understand and testable.
